# AI论文宠物

面向中文人文社科研究与论文写作的 Windows 桌面应用。通过桌面宠物进入论文工作台，围绕项目完成资料整理、研究讨论、数据分析、正文写作与修改、引用核验和 Word 导出。

项目与资料主要保存在本机，文档解析、检索和数据分析在本机完成；AI 对话、任务规划和写作使用用户配置的模型服务。产品会根据当前任务安排工作，创建项目时不要求先确定整篇论文的目录。

## “本地优先”是什么意思

这里的“本地优先”指**数据主要在本机保存和处理，AI 能力可以连接远程服务**，不是“完全离线”或“资料绝不离开电脑”。

| 操作 | 在哪里完成 |
| --- | --- |
| 保存项目、对话、上传文件副本、生成稿、索引和任务存档 | 本机用户数据目录 |
| 文档解析、OCR、资料检索、文件预览 | 本机 |
| Python 数据处理、统计分析和绘图 | 本机受控沙箱 |
| AI 对话、任务规划、写作、改写及历史摘要 | 配置的模型服务；使用远程接口时，任务相关文本、必要历史、资料片段和工具结果会发送给服务商 |
| 网页搜索、公开资料采集、Crossref 书目查询 | 相应外部服务，受权限设置约束 |

网页访问和分析代码联网可在权限页控制，但关闭这两项不会关闭远程模型请求。离线时仍可查看本地项目与文件；依赖远程模型的新对话、写作等功能需要网络和可用的模型配置。API Key 加密保存在本机，调用模型时用于向所配置的服务商认证。

## 运行

使用安装包：Windows 10 1703+/11 x64，安装后直接打开产品；内置 Python 3.14 与统计依赖，无需用户安装 Node.js 或 Python。

### 试用用户安装

1. 从维护者提供的发布附件下载 `AI-paper-pet-PREVIEW-UNSIGNED-版本号.exe`；无需下载源码、`node_modules` 或 `win-unpacked` 文件夹。
2. 运行安装程序，选择安装位置，完成后从桌面快捷方式打开“AI论文宠物”。内置分析环境会占用额外磁盘空间，首次初始化可能较慢。
3. 在设置 → AI 配置中填写自己的模型服务 API Key，保存并测试连接。普通文件阅读不需要模型 Key；AI 对话、写作与分析代码生成会产生服务商 API 费用。
4. 新建项目、导入资料后开始对话。建议先用非敏感样例熟悉分析确认、正文修改、导出和项目备份。

当前试用包未做付费代码签名，Windows 或浏览器可能显示未知发布者或信誉提示，部分设备策略可能禁止安装。出现拦截时保留完整提示并反馈给维护者；不要关闭杀毒软件。签名不是安装软件的强制前提，但本项目不承诺未签名包能在所有设备安装。

遇到问题时请提供版本号、Windows 版本、操作步骤和已遮盖敏感内容的错误截图。不要在公开 Issue 中提交 API Key、论文原文、身份证件或本机数据库。升级前在项目成果中备份项目，保留旧安装包；不要手工删除用户数据目录。

从源码开发：

1. 安装 Node.js 22.19+，准备可运行 pip 的开发用 Python。
2. 在项目根目录执行 `npm ci`。
3. 运行 `python scripts/prepare-python-runtime.py` 准备内置离线分析环境（按官方来源及锁文件验证下载）。
4. 执行 `npm start`，或双击 `start-app.bat`。
5. 在设置 → AI 配置中选择当前支持的服务商，填写 API Key 与模型；可分别配置规划、对话、分析和写作 Agent。已有加密密钥无需重新填写。

当前唯一入口是 `electron/main.js`；工作台是 `src/feed.html` / `src/feed.js`，宠物窗口是 `src/index.html` / `src/renderer.js`。

## 已接通的工作流

- 项目保存学科、论文类型、研究目标与方法等信息，学科不代替研究类型。例如，管理学项目可以采用案例、访谈、问卷、计量等研究方式，不自动固定为案例研究。语言、引用格式、写作风格及 Word 排版统一在设置中调整。
- 论文目录在对话中随研究问题、方法和资料逐步讨论；建议和修改反馈不直接变成正式目录，明确确认采用后才保存。已确认目录用于章节归属和全文组装，项目创建/编辑表单不包含目录编辑器。
- Planner 根据本轮交付意图选择对话、分析、写作 Agent，再生成任务依赖图。工作回顾、基本问答和澄清交给对话 Agent，规划失败时也先对话而非默认写论文。
- 对话回答逐段增量显示在聊天区，原文保存至本对话历史，重启可恢复；不创建论文草稿或 Word 导出入口。对话 Agent 可查阅本对话归档，不加载论文扩写 Skill 或 HTML 输出规则。
- 输入框支持选择文件、选择文件夹和拖入文件夹；递归导入受支持的文件并保留相对路径。文件副本和清单保存在当前项目，跨对话、重启后仍可使用。文献进入该项目知识库，CSV、Excel 等数据单独保留供分析，不进入文献召回。单文件上限 100 MB，单次最多 500 个文件、1 GB；符号链接与开发依赖目录不导入。
- 对话 Agent 读取数据结构、澄清研究目标与方法，提交具体步骤；用户在输入框上方确认当前方案后，分析 Agent 才生成并执行 Python。分析报告和文件入口在对话区展示，点击文件后在右侧单独预览；修改意见回到对话 Agent 形成新版本方案，重新确认后执行。右侧支持文件标签、路径导航、复制、展开、另存和文件夹定位。
- 分析完成不会自动写正文。对话 Agent 另外提交标题、章节、篇幅和采用的结果，用户确认后才交给写作 Agent；仅选中的实际结果表图进入该稿件。专用方法 Skill 和结构化交接规则会同时传入分析代码生成模型。
- 停止任务后保存完成任务与当前部分文本；恢复时复用完成结果，传入新增附件与补充说明。运行中定期存档，异常退出后可恢复最近存档。
- 上传文件和生成文件使用统一的右侧工作区，支持多文件标签、缩放和滚动阅读。PDF 连续查看全文，Excel 按工作表连续查看行列，DOCX 按文档版式展示；复杂文档的字体、分页与排版仍需核对。上传原件只读，生成的正文稿支持编辑。
- 从对话文稿链接或当前项目成果打开右侧全文，可手动编辑，或选中段落润色、扩写、调整实证风格、压缩、译为学术英文和改善论证衔接。修改在完整文章中红删绿增，接受后保存，取消保留原稿；引用或脚注违规变化会拒绝改写，未保存编辑受到保护。不提供稿件历史版本界面。
- 资料库和项目成果始终归属当前项目，并按来源对话组织。正文可指定章节归属，按确认目录组装全文并导出 Word；组装检查缺章、篇幅、引用及方法执行状态，交付标为待核对草稿，不保证自动达到学校终稿要求。
- 权限页控制执行确认、数据工具范围、网页访问、依赖安装和分析代码联网；个性化页支持字体、字号、行距、缩进、页边距及格式要求导入。用户核对并保存排版要求后，用于后续 Word 导出，不改写上传原件。
- 任务过程中按顺序展示进展，工具记录可展开；结束后折叠过程，保留结果摘要、实际文件和变更入口。失败或挂起时说明已完成工作与未完成原因，不把过程输出当成完成结果。
- 核验面板与正文窗口展示已保存的证据原文，正文脚注可跳转至对应片段。旧草稿没有片段快照时需要重新生成。
- 中英文 OCR 模型随源码提供，运行时不下载模型。
- 模型报错或达到输出长度上限时不保存完成稿；正文只保留最终成功响应，工具调用前的过程文字不进入正文。
- 恢复任务时重新上传同名文件会替换旧附件，并清除依赖旧数据的任务产出。实证数据变化或方案版本变化需要重新制定并确认方案；旧版本无确认记录的分析存档不能直接执行。结果、代码、图表、表格和修改历史一并保存。
- 实证检查按表述匹配实际工具结果、附件摘录或已引用的证据原文，检查数值、指标、符号及显著性方向；任意附件或检索命中的存在不再直接放行。规则检查仍不等于完整的语义或统计方法核验。

## 验证

实证流程、方法覆盖与限制见 [实证工作流说明](docs/empirical-workflow.md)。方法索引中的 `available` 表示已提供执行指导和依赖，仍须检查数据与识别条件，不保证模型一定适用、收敛或产生显著结果。

研究 Skill 已加入章节写作、研究设计、数据准备、问卷、质性与文献研究等产品适配指导，以及方法能力查询与检查项。SEM/CFA 等尚未接通的方法执行器会提示能力边界；指导材料不等于已经实现统计计算。脚本成功、结果结构校验通过，也不等于统计正确性认证。不能仅凭选择学科就保证自动完成一篇合格论文。

本轮验收记录：[研究 Skill 与证据链](docs/研究Skill适配与证据链定向验收-20261020.txt)、[管理学研究流程与全文组装](docs/管理学研究类型与全文组装定向验收-20261020.txt)。这些记录区分已验证的定向用例与仍需核验的边界，不代表当前版本通过了全量回归。

`npm test` 运行本地回归测试（含真实 pi 运行时和离线 OCR，模型接口测试使用本机模拟服务）。

`npm run test:ui` 用合成项目在隐藏窗口验证正文选区改写，不操作真实项目。

`npm run diagnose:api` 使用应用已保存的密钥发送一个合成任务，验证真实规划与写作链路，会产生少量 API 用量；结果写入已忽略的 `api-diagnostic.json`，不含密钥或论文。

`npm run validate:real-paper` 为需主动运行的真实文献验证：读取现有资料及已保存的密钥，把相关检索片段发送给配置的模型服务，验证规划、真实资料检索、写作、证据快照、SQLite 保存和 Word 脚注导出。结果仅写入已忽略的 `.real-paper-validation/`，原项目保持只读。可通过 `-- --plan=计划文件绝对路径` 固定项目、文献清单与服务地址；执行前应确认发送范围和 API 用量。普通 `npm test` 不运行此项，也不发送真实资料。

可加 `-- --plan=计划文件绝对路径 --verify-run=已生成验证目录绝对路径` 离线复核已有稿件和导出，不重复调用模型。报告分开记录链路通过和篇幅符合情况；实际生成超出要求时不会把整体结果标为通过。

用户明确的字数要求覆盖项目与 Skill 默认篇幅。正文按汉字计数，排除标题、脚注及引用标记；“约”允许 ±10%，区间与单边限制按明确界限执行，单一精确字数严格执行。多个写作子任务共享总预算。生成后最多自动返修两轮，保留原有引用，并重新执行来源与事实审计；仍不达标时照常保存正文，界面标注实际字数、目标篇幅和“篇幅未达标”，支持查看、编辑与 Word 导出。编辑保存后重新计数；篇幅合格状态与交付完成状态分别记录。

对话原始要求、交付正文和失败/挂起状态按项目及对话存入 SQLite。超过最近 6 个轮次的历史会增量压缩为工作交接包，保留研究目标、约束、已确认决策、完成状态与待办；压缩使用已配置的规划模型，会产生少量 API 用量。重启后复用已保存摘要，最近轮次仍以原文摘录注入规划与写作。需要细节时 Agent 可通过 `read_conversation_history` 读取本对话归档；摘要压缩失败不阻止交付，下轮重试。历史编辑会使受影响摘要失效，删除对话会清除对应归档与摘要。

RAG 索引、缓存与每个证据块都绑定项目；磁盘索引归属、当前文档白名单和正文指纹均参与校验。旧版索引会自动重建，删除或替换资料会使旧召回失效。检索工具不能指定其他项目，挂起恢复也校验项目与证据归属。历史对话中的引文编号不能作为新证据，必须在当前项目重新召回。

## 数据边界

资料文件、SQLite 工作区、草稿、索引、运行存档与 API Key 保存在本机用户数据目录；Key 使用 Electron safeStorage 加密。

调用远程模型时，请求文本、被检索的资料片段、工作文件摘录和工具结果会发送到所配置的服务商。“本地优先”不代表模型推理离线。

模型生成的 Python 强制在 Windows LPAC + Job Object 系统沙箱中执行。每次运行使用独立身份，只读数据副本与专用 Python 运行时副本，仅可写本次输出目录；禁止创建子进程，网络默认拒绝，用户开启对应联网设置时可启用 internetClient；默认限制 1 GB 内存、60 秒执行时间（调用方可按受限范围指定）。停止任务会终止沙箱进程。启动失败或平台不支持时拒绝执行，不降级为普通进程。首次分析会复制科学计算运行时，可能较慢并占用本机磁盘。

运行环境只传入必要变量，不继承 API Key、Token、代理设置。Python 启动需要 `registryRead` 能力；Windows 允许 LPAC 读取的系统资源仍可读取。这是操作系统权限沙箱，不是虚拟机。固定的环境检测脚本在宿主执行；模型生成代码必须进入沙箱。输出量采用轮询限制，不是磁盘硬配额。

`npm run test:sandbox` 使用合成数据验证计算、绘图、越界读写、网络、子进程、内存、超时与取消。沙箱源码和启动器位于 `assets/sandbox/win32/`，`npm run build:sandbox` 使用 Windows .NET Framework 编译器重建。

## 发布

执行 `npm run release:preview` 构建未签名试用包，输出至带时间戳的 `release-preview-*` 目录；签名发布使用 `npm run release:signed`，需要已有可信签名身份。发布脚本会检查依赖、包内文件、签名状态、Defender 扫描结果与 SHA-256。向用户分发 `.exe`、安装说明及 `SHA256SUMS.txt`，不用分发 `win-unpacked`；维护者保留审计报告。首次发布不要跳过测试。

当前版本仍为小范围试用阶段，复杂文档兼容、不同设备性能及真实模型效果需要持续验证。发布检查通过代表本次检查结果，不是无故障或绝对安全承诺。OCR 来源与许可证见 `assets/ocr/models.json`、`assets/ocr/LICENSE` 与 `THIRD_PARTY_NOTICES.md`。

README 按当前本地实现更新于 2026-10-20；安装包实际功能取决于打包版本。旧版 PRD、架构和迭代记录已保留在 docs/archive/20261016/，不能用旧版限制或历史测试数量替代当前状态。

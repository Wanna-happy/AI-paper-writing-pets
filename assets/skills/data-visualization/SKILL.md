# 论文数据可视化执行规程

## 职责边界

**本 Skill 负责**：把真实数据结果、用户材料或理论关系转化为清晰图表/机制图，完成图形选择、字段映射、视觉编码、图题图注、正文解读和一致性检查。

**本 Skill 不负责**：不独立清洗或计算 CSV/XLSX，不生成不存在的数值和图片路径，不以图形替代实证论证，不因论文中出现“图、表”字样就触发。需要先计算真实数据时与 `data-analysis` 联用；没有数据时只提供图表设计或机制示意，并明确假设关系。

## 图表任务定义

从用户任务、工具结果和项目材料中确定每张图要回答的唯一问题，并写出一句内部 takeaway：读者看完这张图应该知道什么。没有真实数据或可用图片时，只输出图表设计方案、字段映射和预期说明，不伪造图形或路径。

## 图形选择规则

| 研究目的 | 优先图形 | 关键检查 |
| --- | --- | --- |
| 单变量分布 | 直方图、密度图、箱线图 | 偏态、离群值、分箱 |
| 组间水平比较 | 点图、箱线图、带区间柱状图 | 样本量、误差线、排序 |
| 时间变化 | 折线图、点线图 | 时间间隔、缺失期、基准 |
| 两个连续变量关系 | 散点图、拟合线与区间 | 离群点、非线性、相关非因果 |
| 相关矩阵 | 热力图 | 变量顺序、色阶中心、系数标注 |
| 模型估计 | 系数图、森林图、边际效应图 | 点估计、区间、基准组 |
| 分类构成 | 分组条形图、100% 堆叠图 | 频数/比例口径、类别过多 |
| 机制与过程 | 机制图、流程图、时间线 | 假设关系与已证实关系区分 |

拒绝用饼图承载过多类别、用截断纵轴夸大差异、用双轴制造关系，或通过选择性删除类别和离群值美化结论。

## 生成流程

1. 从真实工具输出锁定字段、单位、样本、分组、时间范围和缺失处理。
2. 为横轴、纵轴、颜色、形状、分面分别分配一种明确语义，避免同一视觉通道表达多个概念。
3. 选择能显示不确定性的形式；存在区间时优先展示区间，而非只显示显著性星号。
4. 生成后核对图中数值、类别顺序、变量方向和正文表述。
5. 只嵌入工具返回的完整本地图片路径或本轮 `attachment://` 地址。

## 图题与图注契约

图题独立可理解，包含对象、指标及必要的时期/样本范围。图注至少交代：

- 数据来源与分析样本。
- 变量、单位、基准组和缩写。
- 颜色、线型、阴影、误差线或显著性标记的含义。
- 缺失、平滑、标准化或筛选等必要处理。
- 机制图中的实线/虚线分别代表已支持关系还是待检验命题。

## 正文解释协议

在图前说明为什么需要这张图，在图后完成“可观察模式—量级/不确定性—研究含义—边界”。正文不逐点复读图表，也不把视觉差异直接升级为统计显著或因果关系。

## 机制图专项

- 节点使用研究中的真实概念，边说明关系方向和作用性质。
- 区分理论假设、分析路径和经验支持状态；不得把待检验关系画成已确认事实。
- 控制节点数量和层级，保证图能被正文逐一解释，不生成装饰性概念网络。

## 交付结构

依次提供：图表本体或可执行方案、规范图题与图注、正文解释段、数据与解释边界。多图任务再补充统一配色、编号、术语和小数位规范。

## 交付前视觉审计

- 图是否回答单一明确问题，takeaway 是否由真实数据支持。
- 坐标轴、单位、图例、样本与误差线是否完整。
- 是否存在截轴、色阶、面积、排序或筛选造成的误导。
- 图题、图注、正文、表格和工具结果是否完全一致。
- 图片路径是否真实存在，所有图是否在正文中被引用和解释。

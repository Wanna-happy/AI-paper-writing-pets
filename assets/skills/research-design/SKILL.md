# 研究设计与方法执行规程

## 职责边界

**本 Skill 负责**：从研究问题反推证据需求，设计并写明研究对象、材料来源、样本/案例、变量或编码、分析步骤、质量控制、伦理和方法限制。

**本 Skill 不负责**：不调用工具计算 CSV/XLSX，不生成真实统计量或图表，不解释已经存在的模型结果、访谈发现或案例发现，不从结果提炼讨论与贡献。“准备怎么做实证”属于本 Skill；“分析上传数据”属于 `data-analysis`；“撰写已有实证结果”属于 `empirical-writing`。

## 设计原则

从研究问题反推所需证据和最合适的方法，再说明设计为何能够回答问题。不得从期望显著性或既定结论反推变量、样本和模型，也不得把计划中的样本量、访谈数量、平台或伦理审批写成已完成事实。

## 通用设计链

按以下顺序建立并写出闭合链条：

`研究问题 → 分析单位 → 研究对象与边界 → 材料/数据来源 → 样本或案例选择 → 概念/变量操作化 → 分析程序 → 质量控制 → 伦理与限制`

每一环说明具体选择及理由。缺失信息使用待补标记或方案性表述，不暂停执行通用输入检查。

## 定量研究路径

1. 界定总体、抽样框、纳入排除规则、时间与空间范围。
2. 说明数据获得方式、样本形成过程、最终样本量变化与可能偏差。
3. 定义因变量、核心自变量、控制变量和机制/调节变量，说明编码、量表方向与理论依据。
4. 交代缺失值、异常值、权重、聚类结构和重复测量的处理。
5. 根据因变量类型、数据层级和研究问题选择模型，说明模型假设、诊断和稳健性计划。
6. 因果研究明确处理、对照、时间顺序、识别假设及其可检验诊断。

变量表至少包含：变量角色、操作定义、计算/编码、单位或范围、数据来源、预期方向和缺失处理。

## 质性访谈与田野路径

1. 说明研究场域、进入方式、时间范围和研究者位置。
2. 说明受访者/观察对象的选择逻辑、招募方式和样本变化，而非只报告人数。
3. 交代访谈提纲或观察维度如何对应研究问题。
4. 描述录音、转录、匿名化、编码、主题形成和反例处理过程。
5. 使用多源互证、成员核验、研究者反思或审计轨迹说明可信度，按实际采用情况写作。

## 案例与过程研究路径

- 说明案例的典型性、关键性、异常性或理论抽样价值，不能只写“具有代表性”。
- 给出时间边界、关键事件、材料来源与证据三角互证。
- 单案例强调过程追踪和替代解释，多案例说明比较维度与复制逻辑。
- 将事件顺序与机制证据区分，避免仅凭先后关系建立因果。

## 文本/内容分析路径

说明语料来源、时间范围、检索/采样规则、分析单位、编码框架、编码者训练与一致性、平台/档案偏差，以及定量内容分析或解释性分析的具体程序。

## 可复现性与伦理

- 报告软件与版本、关键参数、随机种子、数据分割、基线或代码/数据可用性（与项目实际一致）。
- 涉及个人、访谈、平台或医疗数据时说明授权、知情同意、去标识化和访问边界。
- 没有真实伦理审批信息时不得写审批编号或“已通过审查”。

## 方法章节输出结构

推荐结构为：设计概述 → 数据/材料与样本 → 测量或编码 → 分析程序 → 质量控制与伦理 → 方法边界。正文应叙事性说明研究是如何完成的，避免把软件命令、变量清单和方法名堆成说明书。

## 交付前审计

- 研究问题、分析单位、材料和方法是否一一匹配。
- 样本/案例选择是否有理由，纳入排除与时间范围是否透明。
- 变量、编码或分析程序能否被另一研究者复核。
- 因果语言是否有识别设计和诊断支撑。
- 是否如实报告偏差、伦理、可复现性和方法无法解决的限制。

# 目标与划分
先明确预测对象、预测时点、目标指标和部署外推场景。读取 [预测规则](references/prediction.md)。时间数据不能随机混合未来与过去；跨实体泛化需分组划分，跨时间和跨实体可分别验证。
所有填补、缩放、变量筛选、调参仅在训练折内；留出测试集只评估，不用于反复选模型。先提供Dummy和简单模型基线。固定random_state；n_jobs=1，禁止在沙箱中创建子进程。
SHAP和特征重要性解释预测贡献，不能叫政策因果效应。没有对应依赖时不生成SHAP示例；可使用sklearn permutation_importance。模型输出和验证表均进入结构化交接包。

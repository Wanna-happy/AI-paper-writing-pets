# 执行约束
严格执行已确认步骤 specification，先验证字段、因变量取值、单位、样本、缺失处理和模型秩。保留原始数据，记录每次删样与变换。回归模型递进须对应理论或混杂控制，不自动把所有字段加入回归。因果措辞取决于识别设计，回归系数本身只说明条件关联。
读取 [模型实现规则](references/models.md)。输出每个模型的实际N、估计值、标准误、统计量、p值、95%区间、拟合量、协方差类型、收敛及警告。对 Logit 区分系数、OR和边际效应；多层随机效应不能冒充计量面板固定效应。
按 empirical-result-handoff 的结构交付，代码必须将完整结果写入 PAPER_PET_RESULT 行；没有调用工具不报告任何发现。

# 诊断
使用实际基准模型残差和估计样本；OLS适用BP/White、VIF/秩/影响点与RESET，时序/面板按结构核对自相关。残差正态性不是所有回归的必须准入条件；不按因变量的Shapiro结果机械决定是否能回归。聚类/HAC/HC3根据设计预先指定。少群组或复杂依赖须说明推断限制。
# 稳健性
每步包含基准结果引用、要检查的威胁、实际变更（替代口径/窗口/样本/规格/协方差）、可比较结果、理由和结论边界。不同目标参数、样本和链接函数的系数不能直接按大小比较；不以“仍显著”作为唯一标准，报告方向、大小和区间。替代模型可能改变estimand，应说明。
# 异质性
理论分组预先确定，报告每组N及分组来源。分组回归同一规范与可比较样本；组间差异用合适交互/联合检验。非线性模型比较边际效应和差异需正确协方差，不简单比较Logit系数。连续调节项保留连续/有依据切分，避免随意找切点。
# 图表
PNG Agg、清晰标题轴单位/区间/样本、300dpi适当尺寸，中文字体选择实际可用字体或英文双语，不靠网络下载。系数图优先点估计+CI+零线；异质性可按分组森林图，热力图值明确来自实际指标。不能将显著性星号与效应大小混淆。颜色可读、黑白可区分，不能用装饰隐藏不确定性。

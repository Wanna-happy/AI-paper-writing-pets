# 检验选择
读取 [检验与图表规则](references/inference.md)。每项检验说明针对什么假设、使用哪一基准模型、改变了什么、保持了什么。稳健性不是挑选能显著的方法，不删除异常样本以达到预期结果。
异质性须先确定理论分组与样本规模；“一组显著另一组不显著”不等于组间效应有显著差异，优先交互项联合/差异检验。多重比较、探索性分组和小组样本需说明限制。
默认输出分组系数及区间图/森林图、边际效应图或真实指标热力图。用户说Tableau时澄清静态风格、交互图或可编辑工作簿；本产品默认静态PNG及结果表，不能谎称生成.twb。增加图表需承载真实结果，篇幅由解释展开，不能制造新结果。

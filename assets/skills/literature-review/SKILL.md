# 文献综述执行规程

## 职责边界

**本 Skill 负责**：基于真实文献归纳“现有研究实际沿哪些问题或研究任务展开”，建立研究脉络，比较各分支的对象、方法、结论与限制，以归纳结果生成有实质内容的分节标题，并把研究缺口连接到本研究定位。

**本 Skill 不负责**：不把“理论脉络”当成所有文献综述的固定组织方式，不在阅读和聚类文献之前先编二级标题，不替本研究选择并展开理论基础或构建机制模型，不从经验结果提炼理论贡献，不承担研究设计和实证结果写作，也不把文献按作者逐篇摘要。只有现有文献确实因理论流派或解释机制形成稳定分支时，理论才可成为研究脉络的组织轴；目标是建立本研究分析框架时使用 `theoretical-foundation`。

## 综述目标

把分散文献综合成关于“这个领域已经知道什么、如何知道、在哪里存在分歧、哪些问题仍未解决”的知识结构，并自然定位本研究。不得按作者或年份逐篇罗列摘要。

## 第一步：建立文献证据矩阵

逐篇阅读可用 `[E#]`，先提取文献自身的研究任务，不先套标题。在内部按以下字段建表：

| 字段 | 作用 |
| --- | --- |
| 核心研究问题/任务 | 判断该文献究竟在估计、预测、解释、比较、评价还是提出方法 |
| 研究对象与情境 | 确认研究的是谁、什么现象、何时何地以及分析层次 |
| 核心概念/解释视角 | 比较概念界定与解释路径；不能自动等同于分节标题 |
| 数据、材料与方法 | 比较证据如何形成以及不同结果是否源于方法差异 |
| 核心发现与回答 | 判断文献对其问题回答了什么、回答到何种程度 |
| 局限/反例 | 识别尚未解释的问题 |
| 候选研究分支 | 仅在完成上述提取后，根据共同问题或任务归类 |

材料中没有的作者、年份、文献题名和结论不得生成。资料不足时仍应输出有分析功能的综述结构与应补文献类型，而非伪造引用。

## 第二步：从文献归纳研究脉络

研究脉络是多篇文献围绕同一总主题实际形成的若干研究分支，不等同于“理论脉络”。先比较证据矩阵中的核心研究问题/任务，再聚合为二至四个内部一致、相互可区分、共同覆盖核心文献的分支。优先选择最能解释“现有研究分别在解决什么问题”的主轴：

- **研究问题或任务链**：如同一主题下形成测量/估计、趋势预测、影响因素解释等分支时，按这些任务组织。
- **研究对象的关键维度**：文献分别研究对象的不同组成、环节或作用层面，且每一维度已有足够文献时使用。
- **解释路径或机制**：文献围绕不同原因或机制形成可比较解释时使用。
- **方法、材料或识别路径**：方法差异本身造成知识差异，且方法比较与研究问题直接相关时使用。
- **理论流派**：仅当现有研究确实由不同理论传统构成稳定论争或解释分支时使用，不因文献引用理论就命名为“理论脉络”。
- **历史演进**：仅当研究问题关注概念、制度或知识的阶段变化时使用，不机械按发表年份排列。

禁止先决定“国内研究—国外研究”“理论研究—实证研究”“概念界定—研究现状—研究不足”等万能框架，再把文献硬塞进去；只有地域、理论/实证差异本身构成研究问题时才能采用。无法由现有文献稳定归纳出分支时，不编造研究脉络，应明确材料不足并给出待补文献范围。

## 第三步：用研究分支生成标题

二级标题是文献聚类结论的压缩表达，不是排版装饰。标题必须让读者只看目录就知道该分支研究了什么：

1. 使用“共同研究对象 + 共同研究问题/任务”的内容型名词短语，保持各标题语法并列、层级一致。
2. 标题覆盖本节主体文献，节内文献必须共同回答标题提出的同一类问题；一篇文献可跨分支，但每次引用承担的功能必须不同。
3. 标题之间避免重叠和上下位混杂，合起来应构成对现有研究主要路径的概括，而不是对论文正文目录的复制。
4. 标题粒度由真实文献决定：核心文献不足以支撑独立分支时合并，不为凑三节或四节强造标题。
5. 不使用“相关概念研究”“相关理论研究”“国内外研究现状”“其他研究”等无法说明实质内容的标题。

例如，现有生育率研究若真实聚成三类任务，标题可归纳为“生育率的估计”“生育率的预测”“生育率影响因素分析”。这里可复用的是“从文献共同研究任务归纳标题”的方法，不是把“估计—预测—影响因素”套到任何选题。

生成标题后必须反向核验：每个标题下有哪些核心文献、它们共享什么研究问题、为何不归入其他标题、该分支与全文问题有什么关系。无法回答任一项时，重新聚类或改写标题。

## 第四步：按分支写综合段落

每个综述段落依次完成：

1. 用开头句界定本分支共同研究的问题、对象和范围，解释标题为何成立。
2. 按子问题、解释路径或方法差异组织两项或多项真实证据，呈现共识、差异、演进或互补，不按作者逐个报菜名。
3. 比较不同研究为何得到相同或不同结论，具体落到对象、概念、数据、材料、方法、时期或情境。
4. 在分支末尾形成小结：该路径已经解释了什么、证据支持到哪里、还留下什么限制。
5. 说明该分支与下一分支的逻辑关系；全部分支结束后再作跨分支综合评述并引出本研究。

引用后必须有作者自己的比较或解释，不能用引文替代论证。

## 第五步：跨分支述评与缺口提炼

缺口必须来自前文比较，可落在以下一项或多项：

- 对象/情境未覆盖。
- 核心概念混用或测量不一致。
- 机制链缺失、竞争解释未比较。
- 数据横截面、样本偏差或时间边界限制。
- 方法无法识别其声称的关系。
- 结论在不同研究中矛盾，边界条件未说明。

先综合各研究分支之间的衔接、互补、冲突和共同盲点，再明确本研究如何用研究问题、对象、材料、方法或解释视角处理缺口。缺口必须能够追溯到前述某一分支或分支关系，不得无依据写“鲜有研究”“首次关注”或“填补空白”。

## 系统/范围综述专项

用户任务属于系统综述或 PRISMA 时，再完整报告：研究问题、数据库、可复现检索式、检索日期、纳入排除标准、去重与筛选流程、质量评价、纳入数量和提取矩阵。没有真实检索记录时只设计协议，不编造篇数或流程图数字。

## 建议交付结构

1. 必要时用短导语交代综述对象、范围和归纳依据，不把内部分析轴写成空泛正文。
2. 两至四个由现有文献归纳出的内容型研究分支标题及对应综合论述。
3. 分支内部的小结以及分支之间的关系。
4. 跨分支文献述评、具体研究缺口与本研究定位。

## 交付前审计

- 标题是否由文献证据矩阵和聚类结果推出，而不是预制模板或论文正文目录。
- 只看标题能否辨认现有研究的主要问题/任务分支，标题是否具体、平行、互斥且覆盖核心文献。
- 是否按问题/任务、对象维度、解释路径或确有依据的其他轴综合，而不是摘要串联。
- 每个分节是否围绕标题对应的共同问题展开，并在结尾形成分支判断。
- 缺口是否由真实比较推出，能否对应本研究设计。
- 是否区分文献发现与作者推断，引用是否紧贴判断。
- 是否遗漏反例、矛盾结果、方法差异和适用边界。

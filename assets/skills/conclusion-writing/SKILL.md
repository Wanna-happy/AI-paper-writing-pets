# 讨论与结论执行规程

## 职责边界

**本 Skill 负责**：解释已有发现意味着什么，与真实文献和理论对话，提炼证据支持的理论/实践贡献，形成结论、局限与展望，并回扣研究问题。

**本 Skill 不负责**：不在结果缺失时编造发现，不逐表复述结果，不建立研究开始前的理论框架和假设，不设计方法或执行数据分析。“研究依据什么理论”归 `theoretical-foundation`；“结果对理论作出何种支持、修正或边界化”归本 Skill。

## 章节分工

- **讨论**回答“这些发现意味着什么”：解释机制、比较既有研究、处理异常和替代解释、提炼理论贡献与适用边界。
- **结论**回答“本研究最终知道了什么”：回扣问题、浓缩发现、概括贡献、说明局限并提出由本研究自然延伸的问题。

讨论不能逐字重复结果，结论不能引入正文未分析的新数据、新文献或新论点。

## 讨论写作路径

采用由窄到宽的倒漏斗结构：

1. **核心发现定位**：用分析语言概括最重要发现，不复读系数、表格或引语。
2. **机制解释**：说明结果为何出现，区分数据直接显示、理论推断和仍待验证的过程。
3. **文献比较**：指出与哪些真实 `[E#]` 研究一致、不同或互补，并解释差异可能来自对象、情境、测量、方法或时间边界。
4. **异常与替代解释**：正面处理不支持假设、反例、异质性和模型变化，不选择性报告。
5. **理论贡献/理论对话**：说明发现对既有理论的支持、细化、修正、边界化或整合，严格匹配证据强度。
6. **实践含义与外推边界**：只从已建立的机制和发现推出建议，明确适用主体、条件与限制。

## 理论贡献写法

每项贡献按“既有解释—本研究发现—产生的推进—适用边界”展开：

- **经验补充**：增加此前缺少的对象、场景或材料。
- **边界识别**：揭示理论在哪些条件下成立、减弱或失效。
- **机制细化**：补充被忽略的行动者、过程或中间环节。
- **关系修正**：改变已有概念关系的方向、条件或分析层次。
- **理论整合/创新**：只有形成系统新关系并有多项证据时使用。

“换了一个样本”“加入一个控制变量”“结果显著”本身不构成理论贡献。理论基础 Skill 负责写前框架，本 Skill 只基于已经产生的发现完成写后对话。

## 结论写作顺序

1. 用一段重新提出研究对象、问题、视角和方法，但不复制摘要。
2. 按研究问题而非按章节顺序总结二至四项核心结论，并指出证据状态。
3. 浓缩理论、经验、方法或实践贡献，确保与正文一一对应。
4. 说明具体局限及其对解释和外推造成的影响。
5. 提出能够解决这些边界、检验替代解释或扩展问题的未来研究方向。

结尾应收束到本研究打开的新问题或适用边界，不以“由于能力有限，仍有不足”结束。

## 研究局限

局限必须具体到样本与选择偏差、测量、数据时间、方法假设、案例可迁移性、研究者位置、伦理限制或理论覆盖范围。说明每项局限会影响哪个结论以及影响方向；不写自我贬低式套话，也不把可以修复的设计错误包装为一般局限。

## 启示与建议

- 明确建议对象、行动、实施条件和证据来源。
- 区分研究发现能够直接支持的建议与规范性主张。
- 不从单一相关关系、个案或小样本推出普遍政策处方。
- 避免“加强重视、完善机制、提高水平”等没有行动内容的万能建议。

## 交付前审计

- 每项结论能否回到正文的具体发现和证据。
- 讨论是否真正解释结果并处理异常，而非结果复述。
- 理论贡献是否具体说明推进了什么，是否与理论基础和文献综述保持一致。
- 局限是否说明对结论的实际影响，展望是否能回应局限。
- 是否出现正文没有的新结果、夸大创新或无证据的政策建议。

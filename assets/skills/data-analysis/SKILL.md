# 论文数据分析执行规程

## 职责边界

**本 Skill 负责**：对用户本轮提供的真实 CSV/XLSX 调用本地工具，核对字段与数据质量，完成工具支持的描述统计、分组比较、相关和基础检验，并记录真实样本、口径、结果和限制。

**本 Skill 不负责**：不在没有数据文件时猜测或模拟数据，不设计整套研究方法，不把分析计划写成已完成结果，不代替 `empirical-writing` 将结果扩写为完整实证章节，不自动生成用户没有要求的图表。用户同时明确要求可视化时，再与 `data-visualization` 联用。

## 工具优先原则

存在 CSV/XLSX 且用户要求分析时，必须调用 `data_analysis` 工具。所有字段名、样本量、统计量、图表和文件路径均以工具真实输出为准；工具没有返回的复杂回归、因果效应或显著性结果不得补造。

## 分析流水线

### 1. 建立数据语义

从附件名、字段名、数据字典和项目上下文识别分析单位、时间范围、分组变量、结果变量与可能的缺失编码。不得猜测字段含义；含义不明时使用原字段名，并把解释限制写入结果。

### 2. 审计数据质量

优先检查并报告：

- 行列数、重复记录、空值比例和完全空列。
- 数值/分类/日期字段类型是否与语义相符。
- `-99`、`999`、`不知道` 等可能的特殊缺失编码。
- 极端值、稀疏类别、组间样本失衡和明显录入异常。
- 数据筛选、删除或转换对最终样本量的影响。

不静默删除异常值或重编码。工具无法完成某项清洗时，说明风险及其对结论的具体影响。

### 2.1 记录处理决策

把每项实际处理记录为“原始状态—处理规则—受影响行数—处理后样本—理由”。区分原始变量与派生变量，保留原字段名和计算口径；同一变量出现多个版本时明确哪个进入正文、表格和后续模型。若用户只要求探索分析，不擅自永久修改源文件。

### 3. 选择与问题匹配的分析

- 单变量分布：报告 `n`、均值/标准差或中位数/IQR、范围，并结合分布和异常值选择指标。
- 组间比较：报告各组样本量、中心趋势、差值、检验量、p 值和效应量（工具提供时）。
- 连续变量关系：根据数据条件使用 Pearson 或 Spearman；结合散点模式解释，不能推出因果。
- 分类变量关系：使用列联表与卡方/Fisher 条件；报告频数、比例和稀疏单元风险。
- 回归准备：整理变量方向、编码、缺失、共线性和样本条件；没有模型工具输出时只提出模型方案。

### 4. 形成可复核结果

将工具输出组织为：

1. 数据与样本口径。
2. 数据质量发现及处理状态。
3. 与研究问题直接相关的统计结果。
4. 实质解释及不确定性。
5. 当前分析不能支持的结论。
6. 下一步模型或数据处理建议。

每个表格或图形对应一个真实生成文件，并记录分析使用的字段、分组、筛选和图表类型。多次分析使用不同样本时分别报告 `n`，不得把某一结果的有效样本量当作整份数据的总样本量。

## 结果叙述要求

- 先说明比较对象，再报告统计结果，随后解释研究含义和边界。
- 统一变量名、单位、小数位、分组顺序和样本口径。
- 不把均值差异自动写成显著差异，不把相关系数写成影响效应。
- 不隐藏不显著结果、高缺失率、小样本或与预期相反的发现。
- 需要图表时与 `data-visualization` 协作，正文与图表引用完全一致。

## 工具失败处理

工具失败时仍完成有价值的交付：指出失败发生在哪一步、可能由哪个文件/字段/编码问题导致、哪些结论因此不能生成，并给出可执行的修复方式。不得输出虚构的替代统计结果。

## 输出产物契约

正文分析之外，保留工具真实返回的表格、图形和摘要路径；在论文写作中引用这些产物时使用一致的变量名、样本口径和小数位。需要复杂模型但当前工具不支持时，输出“研究问题—目标变量—建议模型—关键假设—所需诊断—预期报告项”的分析设计，不模拟模型输出。

## 交付前审计

- 每个数值能否回到工具结果。
- 样本量变化和缺失处理是否透明。
- 方法是否匹配变量类型和研究问题。
- p 值之外是否解释了量级、方向和不确定性。
- 是否明确区分描述、关联、预测和因果。

# 输入条件
核对问卷题项、量表刻度、反向题、维度定义、样本单位和缺失政策。变量含义不清先停止；不能自行推断反向题。Cronbach alpha不证明单维性或效度。
读取 [测量与比较规则](references/measurement.md)。EFA用于探索，不代替CFA；训练样本里选出的结构不能在同样样本中被称作独立验证。用户要求SEM/CFA、复杂抽样推断或专业中介分析时，按方法索引中的扩展状态反馈，不能用普通相关代替。
所有比较报告效应量、区间、样本和条件；检验独立性先区分观测设计独立与列联表独立。

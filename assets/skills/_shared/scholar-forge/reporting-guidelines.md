# Reporting Guidelines

Match study type to checklist. Mention compliance in Methods.

| Study type | Guideline | Key items |
|------------|-----------|-----------|
| Systematic review | PRISMA 2020 | Protocol, search, screening flow, risk of bias |
| RCT | CONSORT | Registration, allocation, blinding, flow diagram |
| Observational | STROBE | Design, variables, bias, sample size |
| Animal research | ARRIVE 2.0 | Species, housing, statistics, ethics |
| ML prediction | TRIPOD | Prediction model development/validation |
| Qualitative | COREQ | Researcher reflexivity, sampling, analysis |
| Diagnostic accuracy | STARD | Index test, reference standard, flow |

## PRISMA flow (systematic reviews)

Report counts at each stage:

```
Identified → Deduplicated → Screened (title/abstract)
→ Eligible (full text) → Included → Excluded (with reasons)
```

Include PRISMA checklist as supplementary if venue requires.

## Statistics reporting minimum

- Effect size + uncertainty (CI or SE), not p-values alone
- Pre-specified primary endpoint
- Multiple comparison correction if applicable
- No "trending toward significance"

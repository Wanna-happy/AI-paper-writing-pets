# 社科定量统计分析

## 使用顺序

从当前任务、附件和项目材料中核对研究问题、研究设计、变量类型、数据层级、样本来源、缺失值编码和目标结论，再选择方法。缺失项明确标注，不暂停执行，也不用假设值补齐。任何统计方法都不能修复抽样偏差、错误测量或不成立的因果识别。

报告分析前，说明数据来源、纳入/排除标准、样本量变化、变量操作化、量表方向、缺失值处理和软件/版本；用户未提供的信息标为待补。

## 方法选择

| 研究问题与数据 | 常用方法 | 关键前提/提醒 | 基本报告 |
| --- | --- | --- | --- |
| 一个连续变量的分布 | 均值/中位数、标准差、分位数、直方图 | 检查异常值和偏态；均值不总能代表典型值 | `n`、均值/标准差或中位数/IQR、范围 |
| 两组连续结果是否不同 | 独立样本 t 检验；不满足条件可考虑 Welch 或 Mann–Whitney | 独立性、方差与分布条件；分组规则须预先说明 | 两组 `n`、均值/标准差、差值、检验量、p、效应量与区间（有时） |
| 同一对象前后变化 | 配对 t 检验；不满足条件可考虑 Wilcoxon | 配对关系、变化值分布、失访 | 配对数、均值变化、检验量、p、效应量（有时） |
| 三组及以上连续结果 | 方差分析/ Welch ANOVA；事后比较 | 独立性、方差与多重比较控制 | 各组描述、F/Welch、自由度、p、效应量、事后比较 |
| 两个分类变量是否有关联 | 列联表、卡方或 Fisher 精确检验 | 期望频数、小样本格子、分类定义 | 各格频数/比例、检验量、p、效应量（如 Cramér's V） |
| 两个连续/有序变量关联 | Pearson 或 Spearman 相关 | 线性/单调关系、异常值、不能推出因果 | `n`、相关系数、区间（有时）、p、散点图 |
| 连续因变量的关联/调整 | 线性回归、多元回归、固定效应/层级模型（依设计） | 线性、残差、共线性、独立性、模型设定；调整不自动等于因果 | 系数、标准误/区间、p、样本量、R²、模型设定与稳健性 |
| 二分类因变量 | Logistic 回归 | 事件数、线性 logit、完全分离、解释尺度 | OR 或边际效应、区间、p、样本量、模型设定 |
| 有序/多分类因变量 | 有序/多项 Logistic 回归 | 比例优势或类别模型前提 | 系数/OR、区间、p、类别与基准组 |
| 计数因变量 | Poisson/负二项回归 | 过度离散、暴露时间、零值 | IRR、区间、p、离散诊断 |
| 重复测量或嵌套数据 | 混合效应、GEE、面板模型 | 聚类结构、随机效应/相关结构、时间趋势 | 层级结构、系数、区间、样本与群组数 |
| 处理效应/政策评估 | 实验、匹配、DID、断点、工具变量等 | 每种识别假设不同，必须用设计与诊断支撑 | 识别假设、平衡/趋势/操纵诊断、效应、稳健性与边界 |
| 量表与测量 | 信度、探索/验证性因子分析 | 样本量、题项方向、理论结构、不可只看单一指标 | 题项、样本、信度/载荷、模型拟合（若适用） |

## 方法与证据边界

- 因果表述、准实验、DID、工具变量、断点、面板固定效应和中介/调节分析：从现有材料核对研究设计和识别假设；不能只凭回归结果写“导致”。
- 回归所需信息包括因变量类型、单位、核心自变量、控制变量的理论理由、样本筛选、聚类/固定效应/权重、缺失处理和预先计划的稳健性分析；缺失时只报告当前可支持的分析。
- 多重检验、事后筛选模型或只报告显著结果：必须提示选择性报告风险。
- 小样本、稀疏类别、高缺失率或明显异常值：先报告风险并选择合适策略，不能静默删除。

## 结果解释

先解释估计量的方向、量级、单位和不确定性，再报告 p 值。统计显著不等于实际重要、理论重要或因果关系；不显著也不等于“没有任何效应”。

结果段落遵循“问题/比较对象 → 估计结果 → 不确定性 → 实质含义 → 边界”的顺序。图表和正文分工：图表展示模式或估计，正文说明其对研究问题意味着什么，不能逐格复读表格。

## CSV 初步分析工具

`scripts/csv_analysis.py` 用于用户提供 CSV 的可复核初步统计：描述统计、分组描述、Pearson/Spearman 相关、独立样本 t 检验、列联表卡方、直方图、分组柱状图和散点图。它不代替复杂回归、因果识别、抽样设计或研究者判断。

从附件或数据字典读取编码规则；无法识别时说明风险，不把 `-99`、`999`、`不知道` 静默当作有效数值。工具输出的 p 值和图表都必须结合研究设计再解释。

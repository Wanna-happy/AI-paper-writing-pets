# 社科研究路径路由

## 使用方式

从当前任务和材料中提取“研究问题希望解释什么”与“用户实际拥有什么材料”，再选用下列路径。若二者不匹配，直接指出缺口并按现有证据边界执行，不以写作补偿研究设计缺陷。

## 定量实证

适用于调查、数据库、实验、准实验、面板或统计模型分析。

- 从材料中核对：研究总体与样本、数据取得时间、因变量/核心自变量/控制变量、测量方式、模型与识别策略、缺失值与异常值处理；缺失项标为待补。
- 论证顺序：理论机制或研究假设 → 数据和变量 → 分析策略 → 描述性结果 → 主结果 → 稳健性或异质性 → 解释与边界。
- 写作提醒：不能把相关性写成因果性；不能凭空补足系数、显著性、样本量或稳健性结果；模型选择要说明其与问题和数据的关系。

## 定性访谈与田野

适用于深度访谈、参与观察、民族志、行动研究与质性编码。

- 从材料中核对：进入现场的方式、研究时间与地点、受访者或观察对象、抽样/招募原则、材料类型、分析步骤、匿名与知情同意安排；缺失项标为待补。
- 论证顺序：研究情境 → 材料获得与分析 → 经验主题/过程 → 关键材料 → 机制解释 → 反例或边界 → 理论对话。
- 写作提醒：每则引语都要有必要的语境与分析；不伪造访谈引语、受访者身份或编码过程；研究者位置与伦理问题根据实际情况交代。

## 案例与过程研究

适用于单案例、多案例、组织研究、政策执行与历史过程分析。

- 从材料中核对：案例为何具有典型性、关键性或异常性，时间边界，比较对象，材料来源和关键事件；缺失项标为待补。
- 论证顺序：案例选择依据 → 背景与起点 → 事件/阶段 → 多源证据 → 过程机制 → 与其他案例或理论比较 → 可迁移边界。
- 写作提醒：案例不是故事；每个关键节点须服务于研究问题，结论不应越过案例证据的覆盖范围。

## 政策与治理研究

适用于公共管理、社会政策、基层治理、制度分析与组织协同。

- 从材料中核对：政策文本版本与适用范围、研究层级、主体关系、实施场景、结果指标或经验材料；缺失项标为待补。
- 论证顺序：问题与制度脉络 → 政策设计/执行情境 → 主体互动与资源条件 → 证据 → 机制和阻滞 → 政策含义与适用边界。
- 写作提醒：区分政策文本规定、执行实践和研究者判断；政策建议应从发现推出，不能替代证据。

## 文本、话语与内容分析

适用于新闻、社交媒体、平台文本、档案、政策文本、课程材料和文化传播内容。

- 从材料中核对：文本来源、时间范围、采样与筛选规则、分析单位、编码/解释框架、平台或档案偏差；缺失项标为待补。
- 论证顺序：材料边界 → 分析框架 → 编码/解释过程 → 代表性材料或结果 → 模式与差异 → 理论解释 → 限制。
- 写作提醒：文本例证必须可追溯；避免将少量文本的现象扩展为总体事实。

## 混合方法

适用于定量与定性、文本与访谈、案例与统计的组合。

- 从材料中核对：两类方法分别要回答的问题、实施先后、相互验证还是解释关系、出现矛盾时如何处理；缺失项标为待补。
- 论证顺序：总问题 → 各方法的角色与材料 → 分项发现 → 交叉解释 → 一致/不一致证据 → 综合结论。
- 写作提醒：两种方法都要承担不可替代的任务；不要只把两个研究并排拼接。

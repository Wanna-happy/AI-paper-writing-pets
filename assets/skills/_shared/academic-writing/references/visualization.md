# 数据可视化与表图规范

## 绘图上下文

从当前任务、附件和项目材料中提取图表要回答的研究问题、变量含义和单位、分析样本、时间/空间范围、比较对象、缺失值处理及格式要求。缺失信息只限制图表解释强度，不触发通用提问。图不是装饰：每张图或表只服务一个可说明的结论。

## 图表选择

| 目标 | 优先形式 | 避免 |
| --- | --- | --- |
| 展示单变量分布 | 直方图、密度图、箱线图 | 只报均值掩盖偏态/离群值 |
| 比较类别或组别 | 点图、带区间的柱状图、箱线图 | 截断纵轴夸大差异；把均值柱当成全部分布 |
| 展示时间变化 | 折线图、点线图 | 不规则时间间隔却等距呈现；无说明地连接缺失期 |
| 展示两个连续变量关系 | 散点图、拟合线与区间 | 用相关图暗示因果；隐藏离群点 |
| 展示模型结果 | 系数图/森林图、预测概率或边际效应图 | 只给星号、不报告点估计和区间 |
| 展示分类构成 | 100% 堆叠条形图、热力表 | 类别过多的饼图；同时比较数量和比例却不说明 |
| 展示空间差异 | 地图（有可靠地理边界时） | 使用不合适投影或把人口规模差异当作地理效应 |
| 展示过程与机制 | 时间线、过程图、机制图 | 将假设机制画成已经证实的事实 |

## 图表通用规范

- 标题能脱离正文被理解，说明对象、指标、时期和比较方式。
- 轴标签写清变量、单位和比例基数；颜色有明确含义，避免只靠颜色区分信息。
- 图注交代数据来源、样本量、缺失处理、误差线含义、显著性标记和必要缩写。
- 表格保留读者判断所需的样本量、单位、统计量、模型列和注释；不把截图作为最终表格。
- 同一论文维持颜色、分组顺序、小数位、统计符号和术语的一致性。
- 不通过裁剪坐标轴、选择性类别、移除离群值或不说明平滑方式制造视觉结论。

## 可运行工具

使用 `scripts/csv_analysis.py` 前，先查看列名和数据字典。示例：

```powershell
python scripts/csv_analysis.py survey.csv --numeric income,age,score --group gender --out analysis
python scripts/csv_analysis.py survey.csv --scatter income,score --correlation spearman --out analysis
```

工具将输出 Markdown 报告、CSV 表和 PNG 图。用户应保存原始数据与运行参数；在论文中复现时补充数据版本、清洗规则、软件环境和图表生成日期。

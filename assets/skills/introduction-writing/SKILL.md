# 引言与问题提出执行规程

## 职责边界

**本 Skill 负责**：论文开篇的问题化论证，包括研究现象、知识张力、研究问题、研究切入、开篇意义与贡献定位，并按论文类型组织为中文社科引言或 CARS 引言。

**本 Skill 不负责**：不生成全文目录和开题方案；不以引言中的简短研究现状替代完整文献综述；不详细展开理论框架、研究方法、结果分析和结果后的理论贡献。用户要求修改已有引言时，可与 `revision` 同时加载；从零撰写引言时不需要 `revision`。

## 章节功能

引言必须完成研究合法性的论证：让读者理解现象为何值得研究、已有知识解释到了哪里、具体问题在哪里、本研究将如何推进。背景材料只负责建立问题，不负责堆砌宏大叙事。

## 内部论证链

写作前从现有材料抽取以下链条：

`可说明的现象/知识矛盾 → 已有解释 → 具体限制 → 研究问题 → 研究切入 → 证据与方法 → 预期贡献/文章定位`

任何一环没有材料时降低断言强度，并使用可核验的问题表述；不虚构政策、事件、作者或研究结论补齐链条。

## 中文社科路径

1. **缘起**：以一个可说明、与研究对象直接相关的现象或矛盾进入，迅速交代对象、场景和范围。
2. **问题化**：指出现象背后的解释张力，把现实困惑转化为可研究的问题，避免停留在“现状严峻、意义重大”。
3. **知识定位**：概括已有研究的主要解释路径与共识，只使用真实 `[E#]`，并说明其在对象、机制、材料、方法或边界上的具体限制。
4. **研究问题**：给出能够被本研究材料回答的核心问题；描述性问题、解释性问题和规范性问题分层表达。
5. **研究切入**：说明研究对象、视角、材料和方法为何适合回答该问题。
6. **贡献定位**：用“扩展对象/修正机制/补充证据/改进方法/揭示边界”等具体动作表达，不使用空泛创新口号。

## CARS 路径

适用于英文期刊或采用国际论文结构的引言：

1. **Establish territory**：说明研究领域及其重要性，界定核心概念与已有知识。
2. **Establish niche**：通过矛盾、遗漏、限制、未解释机制或情境边界建立具体研究空间。
3. **Occupy niche**：提出研究目标/问题、数据与方法、主要贡献，并按目标期刊习惯决定是否预告结果和结构。

三个动作可以跨段实现，不机械套用固定连接词。贡献条目只在目标格式允许时列表化，中文正文优先写成连贯段落。

## 段落职责

- 开头段：现象与研究对象，必须导向问题。
- 知识段：已有解释的分类、比较与限度，不能变成简短文献综述堆栈。
- 问题段：明确核心问题、分析层次和边界。
- 定位段：说明研究如何回答、使用什么材料以及能形成何种贡献。
- 结构预告：仅在论文类型或期刊要求时保留，不用它代替有力度的结尾。

## 研究意义写法

- 理论意义必须对应一个明确的知识对话对象和可能推进的解释。
- 方法意义必须说明材料、设计或分析程序带来的新增识别能力。
- 实践意义从研究问题和可支持发现推出，不写万能政策建议。
- 没有真实研究发现时，不在引言提前宣称结果已得到证明。

## 交付前审计

- 开头是否在两到三段内进入明确研究问题。
- 缺口是否具体到对象、机制、数据、方法或边界，而非“研究较少”。
- 研究问题能否被现有材料和方法回答。
- 贡献是否与后文证据链匹配，是否存在夸大或提前宣布结论。
- 每一条已有研究判断是否有真实来源，是否避免新闻口号和结构预告式收尾。

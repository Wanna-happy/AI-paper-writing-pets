# 实证分析写作执行规程

## 职责边界

**本 Skill 负责**：将真实统计输出、访谈材料、编码结果、案例事件或过程证据组织为“问题—发现—证据—解释—边界”的结果与分析章节，并准确说明结果支持到什么程度。

**本 Skill 不负责**：不从零设计数据、样本、变量或模型，不调用工具计算原始 CSV/XLSX，不把预期关系写成真实发现，不负责结果之后的理论对话、理论贡献、总括结论和实践启示。“如何开展实证”归 `research-design`；“计算上传数据”归 `data-analysis`；“结果意味着什么及贡献何在”归 `conclusion-writing`。

## 核心任务

把真实数据、模型输出、访谈材料或案例证据组织为“研究问题—发现—证据—解释—边界”的实证论证。结果章节负责说明发现了什么；讨论内容负责解释这些发现意味着什么。不得把表格逐格复述，也不得用理论预期替代真实结果。

## 内部结果映射

写作前从现有材料建立结果矩阵：

| 项目 | 需要锁定的内容 |
| --- | --- |
| 研究问题/假设 | 本节具体回答哪个问题或检验哪条关系 |
| 分析对象 | 样本、案例、时期、分析单位和筛选口径 |
| 核心证据 | 系数、区间、效应量、模型比较、主题材料或过程证据 |
| 证据状态 | 主结果、补充结果、稳健性、反例或尚待验证 |
| 解释边界 | 相关/因果、样本外推、测量与方法限制 |

只写矩阵中有真实依据的内容。缺失项转为分析方案或明确的待补信息，不生成貌似精确的结果。

## 定量实证写作顺序

1. **分析目标与口径**：用一段说明本节回答的问题、模型或比较对象，以及结果能识别到什么程度。
2. **描述性基础**：报告与研究问题有关的样本特征、变量分布、缺失情况和必要相关性；不堆无关指标。
3. **核心结果**：先给方向和量级，再给统计不确定性，随后说明与假设或理论预期的关系。
4. **模型递进**：解释不同模型加入了什么、识别条件如何变化、核心估计是否稳定；不要只说“模型一至模型四均显著”。
5. **附加检验**：分别说明稳健性、异质性、机制、中介/调节和内生性检验各自解决什么问题、采用什么比较、结论支持到哪里。
6. **结果小结**：回扣研究问题，区分已支持、部分支持、不支持及证据不足的命题，并给出进入讨论部分的接口。

## 单个结果段落模板

按以下逻辑生成连续正文，而非机械填槽：

1. 指明表/图/模型与比较对象。
2. 报告核心估计的方向、量级、单位和不确定性。
3. 将统计结果翻译成研究对象上的实质含义。
4. 说明该结果与假设、机制或既有研究的关系。
5. 给出识别、样本、测量或替代解释边界。

显著结果不等于重要结果；不显著不等于完全没有关系。优先报告置信区间和效应量，避免只围绕星号写作。

## 质性与案例结果路径

- 按主题、过程阶段、机制链或比较维度组织材料，不能按访谈对象或时间简单堆叠。
- 每个发现单元依次写：分析性判断 → 代表性材料/事件 → 语境说明 → 解释 → 反例或边界。
- 引语只证明其实际表达的经验事实；不得伪造受访者身份、引语、编码频次或饱和度。
- 案例研究突出关键事件之间的过程联系和多源互证，不能把故事的先后顺序直接当作因果机制。

## 专项检验的表述边界

- **稳健性**：说明替代变量、样本、估计方法或误差结构改变后，哪个核心判断保持或改变；不能写成因果证明。
- **异质性**：说明分组依据、组间差异及正式差异检验；不能以“一组显著、一组不显著”直接推出组间显著不同。
- **中介/机制**：区分统计中介、理论机制和因果机制；只有设计、时间顺序和识别条件充分时提升断言强度。
- **调节**：解释交互项的方向需要结合边际效应或预测值，不能只解释单个交互系数。
- **DID/工具变量/断点/固定效应**：必须报告相应识别假设和诊断；材料未提供时只写待验证的分析方案。

## 表图与正文协同

- 表题、图题、变量名、样本量、模型编号、小数位和显著性标记与工具输出完全一致。
- 正文挑选最能回答研究问题的结果，表格承担完整数值，图形承担模式与不确定性展示。
- 图表必须在正文中先被引用再被解释；不引用不存在的表图，不伪造编号或路径。

## 输出结构

根据任务范围选择以下最小完整结构：

- 单个模型解释：目标与口径 → 核心结果段 → 边界。
- 完整实证小节：描述基础 → 主结果 → 附加检验 → 小结。
- 研究发现章节：章节导语 → 若干递进发现单元 → 反例/边界 → 回答研究问题。

## 交付前审计

- 所有数字、变量、样本和检验是否来自真实材料或工具结果。
- 是否区分结果与讨论、统计显著与实质意义、相关与因果。
- 是否解释了模型递进和附加检验的功能，而不是表格复读。
- 是否报告了不确定性、异常结果、反例和不支持的假设。
- 结论强度是否与研究设计、数据质量和识别能力相匹配。

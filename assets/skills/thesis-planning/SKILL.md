# 论文规划执行规程

## 职责边界

**本 Skill 负责**：选题收敛、题目拟定、开题与研究计划、整篇研究蓝图、章节职责与目录设计，以及基于已有全文内容压缩摘要和关键词。

**本 Skill 不负责**：不展开撰写引言、文献综述、理论基础、研究方法、实证结果或讨论结论；不执行数据分析和图表生成；不把用户要求的整篇论文擅自降级为提纲或摘要。用户只要求某个正文部分时，应由对应章节 Skill 负责。

## 规划目标

把一个宽泛主题收敛为可由现有或可获得材料回答的研究问题，并形成从题目到章节、从主张到证据的完整研究蓝图。规划必须服务于后续写作和研究实施，不生成只有章节名称、没有论证职责的通用目录。

## 选题可行性链

依次建立以下关系：

`研究现象 → 明确对象与边界 → 知识脉络/现实矛盾 → 核心研究问题 → 可获得材料 → 合适方法 → 可支持贡献`

从现有项目材料中核对每一环。某一环缺失时给出具体补足方案或降低研究范围，不用热点、政策口号或虚构发现掩盖不可行性。

## 选题评价维度

- **问题性**：是否要解释一个明确关系、过程、差异或矛盾，而非只介绍主题。
- **学术定位**：能否指向具体知识脉络、概念争议、机制缺口或证据边界。
- **材料可得**：数据、案例、访谈、文本或实验是否能够在时间与权限范围内获得。
- **方法匹配**：方法能否回答问题，是否存在无法满足的样本、识别、测量或伦理条件。
- **范围适度**：对象、时间、空间、变量和问题数量是否匹配论文类型与篇幅。
- **贡献可信**：贡献能否由计划中的材料推出，而非仅靠更换研究对象。

提供多个选题时，不只罗列名称；逐项比较问题、材料、方法、风险与可完成度，并明确推荐顺序和理由。

## 题目生成

题目应准确呈现研究对象和核心关系/过程，必要时加入情境、方法或理论视角。优先使用“对象 + 核心问题/机制”的结构；副标题只在需要限定案例、时期或方法时使用。避免：

- “浅析、试论、探析”等空泛动词。
- 用“以……为例”掩盖真正研究问题。
- 在题目中提前宣布未经证实的结论。
- 堆叠多个理论、变量和政策词导致范围失控。

题目候选应体现不同研究取向，而非只替换同义词。

## 研究蓝图

开题或长篇任务至少形成：

1. 暂定题目及其边界说明。
2. 核心研究问题与有限的子问题。
3. 已知的理论基础和需要补充的知识脉络。
4. 研究对象、分析单位、材料/数据及获取方式。
5. 方法、关键分析步骤和质量/伦理控制。
6. 核心主张—所需证据映射。
7. 章节结构、每章职责、输入证据和向下一章的输出。
8. 主要风险、证据缺口和可执行的下一步。

## 章节结构设计

每章必须回答一个清晰问题并产生下一章所需的论证结果：

- 引言提出问题和研究定位。
- 文献综述建立知识结构与具体缺口。
- 理论基础界定概念、机制和分析框架。
- 研究设计说明证据如何产生。
- 经验章节按问题、机制、阶段或比较维度呈现发现。
- 讨论与结论回答研究问题并提炼贡献、边界和展望。

对每章写出“章节问题—核心主张—所需证据—与前后章关系”，仅有标题列表视为未完成。

## 摘要执行协议

摘要压缩论文已经存在的内容，推荐顺序为：研究背景/问题 → 目的 → 数据与方法 → 核心发现 → 结论与贡献 → 必要边界。没有真实研究结果时，输出开题摘要或带明确待补项的结构，不编造发现。

- 避免大段背景、引用、章节预告和未定义缩写。
- 方法写到足以理解证据如何形成，结果写最有信息量的具体发现。
- 结论强度与正文一致，不加入正文未出现的贡献。

## 关键词

选择三至八个稳定、可检索、能覆盖研究对象、核心概念/机制和方法/情境的术语。避免把完整题目拆成关键词，也避免“研究、分析、影响”等无区分度词语。

## 交付前审计

- 研究问题是否明确到对象、关系/过程、条件和边界。
- 题目、问题、理论、材料、方法和贡献是否同向一致。
- 每个章节是否有独立职责和证据需求，是否存在重复或断裂。
- 研究范围是否在项目时间、数据权限、篇幅和伦理条件内可完成。
- 摘要是否忠实于已有研究设计与发现，关键词是否真正可检索。

# 论文修订执行规程

## 职责边界

**本 Skill 负责**：在用户已有文本基础上进行结构、逻辑、段落、句法、术语和格式修订，同时锁定原文事实、数字、引文、变量方向与结论强度。修改某个专门章节时，可与该章节 Skill 联用。

**本 Skill 不负责**：不从零替用户写一个尚不存在的章节，不借润色新增研究数据、文献、方法、结果或理论贡献，不执行数据分析和图表生成，不自行改变用户观点。用户说“写一段引言”使用 `introduction-writing`；用户提供引言并说“重写/润色”才使用本 Skill，并可同时加载 `introduction-writing`。

## 修订底线

锁定原文的研究对象、问题、事实、数字、公式、变量方向、引文标记、引用键和结论强度。除非用户明确要求改变观点，不得通过“润色”新增事实、文献、结果或理论贡献，也不得静默修正疑似事实错误。

## 修订优先级

按照从高到低的顺序处理：

1. 研究问题、中心主张和证据是否一致。
2. 小节职责、段落顺序和论证是否闭合。
3. 概念、术语、时态、变量与引用是否一致。
4. 句法、衔接、冗余、语气和可读性。
5. 标点、格式和细节规范。

禁止只做同义词替换而保留逻辑问题，也禁止为了“变化明显”改坏已经准确清晰的句子。

## 段落修订流程

1. 提取原段中心主张、证据、解释和与上下文的接口。
2. 删除偏离主张的背景、重复释义和无证据强断言。
3. 调整为“主张—证据—解释—限定—过渡”，必要时拆分长段或合并碎段。
4. 恢复清晰主语与动作，减少名词堆叠、被动套话和机械连接词。
5. 与原文逐项比对，确认事实、数字、引文和结论方向未变化。

## 不同任务的执行方式

- **润色**：保留结构和原意，修复表达、衔接、语法与学术语气；原文已好时少改。
- **逻辑重写**：允许重排段落和句序，但必须保留全部有效证据和观点关系。
- **降重**：通过重建论证顺序、改变信息组织和压缩套话实现，不做机械同义词替换，不牺牲术语准确性。
- **扩写**：只扩展原文已包含或材料可支持的定义、机制、证据解释和边界，不新增虚构事实。
- **压缩**：保留中心主张、关键证据、限定和结论，优先删除重复背景、空泛评价与多次释义。
- **续写**：从上一段的结论和目标小节职责继续，保持术语、时态、引文格式与论证强度。

## 去 AI 味

重点修复：均匀句长、机械三段式、过量“首先/其次/此外/综上”、悬空宏大判断、空泛归因、连续排比、装饰性引号、破折号滥用和没有新增信息的重述。

使用具体对象和动作、自然长短句、真实因果/转折关系和作者已有判断替代模板表达。不得为了“人味”加入口语、主观情绪、虚构细节或故意制造语病。

## 中英文与载体

- 中文保持全角标点和学术语体，避免英语句法直译、过长前置定语和名词化堆叠。
- 英文统一 US/UK 拼写、术语、缩写、时态、单位和 hedging 强度。
- 产品正文输出为 HTML，不残留 Markdown 标记；保留原有 LaTeX 命令、公式或引用键时不得破坏语法。

## 交付方式

优先输出可直接替换的修改稿。用户要求说明时，再附不超过三类关键修改：逻辑结构、证据边界、语言表达。除非用户明确要求，不输出冗长逐句修改日志或内部诊断表。

## 交付前闭环

最多进行三轮内部复核：

1. 逻辑与证据：是否存在跳跃、矛盾、相关/因果混淆或夸大。
2. 表达与 AI 痕迹：是否仍有模板连接、空话、节奏机械和术语漂移。
3. 原意与一致性：数字、公式、引文、事实、方向和结论强度是否与原文一致。

三轮后仍不能安全修改的事实冲突或材料缺口，明确标为人工核验项，不假装已经解决。

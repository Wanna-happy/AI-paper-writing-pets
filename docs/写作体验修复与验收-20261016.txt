写作体验修改与验收记录
日期：2026-10-16

范围
对应《写作助手体验差距与候选修改方案-20261016.txt》，纳入用户后续修正。
原方案是修改前的审查记录，不代表当前状态。以下是源码实际实现及验证范围。
保留现有 harness 和每轮动态规划，不固定完整论文流程。
本轮在共享目录增量修改，未回滚其他对话的工作，未重启正在运行的产品。

已实施
UX01 统一稿件入口：历史消息和成果页均在右侧打开当前稿，支持编辑、保存、撤销上次修改。
UX02 全文修订：展示完整文章，在原位置红删绿增；取消保留原稿，接受后保存；原稿变化时拒绝覆盖。去掉段落预览页标题及返回层，保留缩放。
UX03 按用户最新决定撤销：移除稿件历史版本入口、命名/恢复界面及版本数量提示。保留已有保存数据，不删除用户历史内容。
UX04 项目成果：属于当前项目，与资料库同步切换；可按文稿、方案、表格、图表、数据副本和代码筛选，直接打开真实结果文件。长论文沿用已有章节控制和组装来源选择。
UX05 动态任务衔接：保留现有意图、规划、执行与授权机制；意图、修复、分派权限和任务依赖自动化测试通过。没有修改成固定论文模板。真实付费模型长链路质量尚未实测。
UX06 阶段与结束反馈：现有按顺序的阶段消息、产物入口、h/m/s耗时、可展开过程和失败恢复均通过回归。任务结束后隐藏任务卡，保留总结及文件；恢复动作不注入长用户消息。
UX07 资料库：支持正文、作者、年份、标签搜索及筛选；可在右侧修改元数据；显示可能重复资料而不自动删除。状态改为可用于写作、需要识别、待处理等；修复按钮竖排和跨项目异步索引结果覆盖。
UX08 引用与交付检查：缺少出处、来源不全、原文片段待核对形成清单；可定位证据或正文，标记来源片段已核对，打开只读原资料。人工片段核对不等于整篇论断已获验证。
UX09 项目创建：先填名称和类型，细节折叠按需补充，默认课程论文；长论文档案保留，不强迫所有任务填写。
UX10 模型设置：高级地址和独立 Agent 配置按需展开；修改输入后旧连接成功状态失效；区分未测试、未保存和连接成功；测试期间输入变化不会把旧结果当作新配置成功。自定义中转入口保持停用。
UX11 文件阅读：上传/生成文件统一右侧预览；保留 Word、PDF、表格完整阅读与缩放，增加查找定位和本次应用会话内的按文件缩放记忆。表格回退预览也有缩放；修改稿未保存时阻止切换文件或关闭。
UX12 导出检查：导出前展示当前保存稿件、篇幅和待核验问题；组装使用所选章节稿。系统另存为保留，学校/期刊模板库未作为本轮新增功能。
UX13 操作细节：保持现有设计样式；资料编辑、导出检查和全文修订使用右侧区域；改写接受操作在长文底部保持可达。键盘保存、选区操作、预览标签切换、窄窗口与焦点返回保留。
UX14 备份恢复：项目备份包校验文件和标识，恢复独立副本，不覆盖原项目、不携带模型密钥。恢复后关闭原项目右侧内容；任务执行中和存在未保存编辑时阻止备份/恢复。

本轮验证
1. scripts/writing-workbench-smoke.cjs：全文修订、取消/接受、撤销、手动保存、防丢稿、移除历史入口、成果分类及文件直达、资料筛选/正文搜索/重复提示、文献信息保存、引用定位、缩放记忆、模型设置状态、项目隔离、窄窗口、非模态稿件交互。
2. scripts/ui-smoke.cjs：既有编辑、引用保护、证据跳转、恢复、流式对话、进度、独立Agent设置、方案确认、文件预览、澄清及文件夹上传通过。
3. scripts/upload-preview-ipc-smoke.cjs：真实文件导入和受约束IPC、五页DOCX表格图片及末页、上传/生成十六页PDF、CSV链接、缩放、未发送附件和只读约束通过。归属拒绝错误是预期的隔离断言。
4. scripts/turn-completion-smoke.cjs、scripts/resume-milestones-smoke.cjs：顺序进度、耗时、结束折叠、阶段成果、失败收尾、恢复动作和历史过程通过。
5. pipeline-policy、intent-flow、intent-repair、task-progress：动态任务理解、权限、步骤依赖、失败与恢复状态通过。
6. project-backup、document-search、preview-bundle、text-diff：备份内容与校验、跨项目审批隔离、PDF末页查找、内嵌渲染器同步和CSP、全文差异重建通过。

边界
界面及Agent测试使用隔离合成数据/模拟模型，文件预览测试使用真实格式测试文件；未操作真实论文或密钥，未请求付费模型。
Word浏览器渲染不能保证复刻全部Office排版功能；已有复杂格式样本通过不等于任意文档均保真。
缩放记忆当前为应用会话内记忆，不承诺跨重启保留。
重复资料是提示，不执行自动删除；未增加联网DOI补全、云协作或学校模板目录。
备份保存资料、稿件和产物，不迁移运行中的Agent进程；新项目不能继承旧项目审批。
未执行屏幕阅读器全流程或宣称WCAG合规，未重新打包发布安装程序。

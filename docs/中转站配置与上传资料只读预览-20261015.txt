中转站配置与上传资料只读预览
日期：2026-10-15

一、中转站配置问题与修改

1. 截图中自定义接口使用 custom-model。
这是占位名称。中转站虽然可以提供多个模型，但每次请求仍须指定真实模型 ID。
修改：增加“获取可用模型”，使用当前接口和用户填写的密钥，或同服务商同地址已保存的密钥读取 /models；列出多个模型供用户选择，也保留手动填写。
没有模型列表或接口不支持该功能时给出提示，不猜测或自动选择模型。custom-model 占位名称不能进入连接测试。

2. 自定义密钥输入框仍显示 DeepSeek 提示。
修改：提示随当前服务商变化；切换服务商或地址后清空旧的模型列表，防止误选其他站点的模型。

3. 连接失败只显示 fetch failed 和 IPC 包装。
修改：区分证书、域名解析、连接超时与拒绝连接；UI 去除 IPC 错误包装。连接测试增加超时。
桌面端 API 测试、模型列表以及实际 Agent 模型调用使用统一桌面网络传输，沿用桌面的代理与证书配置；Node 测试环境仍使用标准 fetch。
保留 HTTPS 和证书校验，不关闭安全校验，不把已保存密钥发到其他地址。

实际匿名诊断：
- 未发送 API Key、研究资料或付费模型请求。
- 授权环境中的 Node 检查返回 DEPTH_ZERO_SELF_SIGNED_CERT。
- 桌面网络栈复查同样没有通过证书校验。
- 失败发生在 TLS 层，尚不能判断用户密钥、余额或具体模型是否有效。
- 证书可能来自中转站或本机代理链路；本轮未进一步确定签发链来源。需要确认中转站证书链与本机代理/系统信任配置，不能通过本产品代码假装连接成功。

建议使用顺序：填写中转站接口地址与密钥，读取可用模型，选择实际模型，再测试并保存。若先出现证书错误，应先解决证书或代理信任配置。

二、上传资料预览问题与修改

1. 文件卡片不能点击预览。
修改：点击或通过键盘激活附件卡片，在右侧打开原始上传资料的只读预览。后端按项目/对话查找附件 ID，不接受任意文件路径。

2. 原始上传资料不能在平台编辑。
修改：上传资料使用独立只读预览类型，不显示方案编辑器、可编辑正文或保存覆盖入口；阻止上传预览进入生成文件的导出/覆盖路径。
Agent 生成的方案和正文继续使用原有编辑功能。

3. 大量 .venv-thesis/Lib 文件占满对话。
修改：目录导入跳过 .venv-thesis、其他 venv 前后缀环境目录及 site-packages 等。历史附件只在展示层隐藏环境目录文件，不删除用户原文件或历史记录。
正常附件默认显示前4个，其余通过“其他附件”展开。

预览范围：
- PDF：渲染原始页面，当前显示前3页，并标明总页数。
- Word：正文文本只读预览，不复刻完整 Word 排版。
- Excel：首个工作表最多200行、30列，显示原始单元格值；不计算公式、不改写文件。
- 图片、文本、CSV、Markdown、JSON、代码等：只读内容预览；文本最多200000字符。
- ZIP：只显示目录，不执行包内内容。
这些范围均为预览限制，原始文件保持完整。

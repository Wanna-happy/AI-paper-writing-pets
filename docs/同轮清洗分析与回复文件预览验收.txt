同轮清洗分析与回复文件预览（2026-10-13）

用户体验：
用户要求清洗后分析 → 实际生成清洗副本 → 缺少信息时在当前任务显示逐题卡片 → 实际提交具体分析方案 → 用户直接确认或修改 → 原任务执行分析 → 回复内文件链接打开右侧预览。
方案确认会继续原始 run，不创建新用户指令或另一轮生成。修改方案也在同一任务完成。模型仅说“下一步提交”不能被当作完成交付；编排器要求实际提交工具，否则报告未完成。

文件展示：
正文、结果表、图片、代码、结果 JSON 与清洗 CSV 支持实际文件入口。回复内 artifact:// 链接由产品拦截，打开右侧对应文件；路径由后端当前项目/对话与结果版本解析，不允许模型任意指定本地路径。历史分析回复按真实已存产物补充链接。较长说明折叠时文件链接保持可见。
清洗 CSV 可以在右侧查看并另存。原始数据不改写。每个产物有独立文件卡片，避免必须先进入总入口再找文件。

交互约束：
待确认响应绑定发起窗口、项目、对话、任务及精确版本。跨窗口/项目/对话、旧版本、重复响应拒绝；取消任务会释放等待。确认之前不运行模型分析。
前置意图澄清回答后在同一任务重新识别目标。卡片的建议答案不自动当作确认。未选方法或不明编码仍通过必要问题确认，不自行猜测。

验证：
完整 pi Agent 集成测试采用模拟模型决策，但清洗及分析实际在产品 Windows 沙箱运行；单个用户任务经过清洗、直接问答、方案修改、确认、分析，真实均值正确，原文件保持一致，结果含文件链接。
隐藏独立 Electron 窗口验证了回复链接打开正文、表格、清洗副本，以及等待期间按钮可点并继续原 run。Markdown 安全过滤回归通过。
交互等待、旧版本与跨范围响应拒绝、取消清理、规划前问答续接均有专项测试。

运行状态：
没有重启用户正在使用的产品，没有写入真实用户工作区数据库；主进程改动需要重新启动最新源码版本后生效。

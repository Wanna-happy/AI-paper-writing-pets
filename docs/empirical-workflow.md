# 社科实证研究工作流（0.1.3）

## 用户操作

1. 在当前项目对话上传 CSV/XLSX，说明研究问题、论文类型与篇幅、变量含义及希望采用的方法。对话 Agent 检查实际字段、类型、缺失和样本规模；只追问会影响交付的缺口。
2. 对话 Agent 提交分析方案，在输入框上方展示。展开查看变量、模型、标准误、检验目的与表图安排；可以先提出修改。点击“确认方案并分析”才执行该版本。
3. 分析报告、样本量、诊断和修改反馈在中间对话区展示。报告下方提供结果表、PNG、Python 代码、结果 JSON 文件入口；点击才在右侧打开单个文件。右侧提供文件标签、关闭、路径导航、展开、复制和另存，不包含报告或反馈输入框。论文草稿也可以从对话中的文件入口在右侧预览并导出 Word。四个及以上计划步骤才显示任务进度卡。
4. 提交修改意见，由对话 Agent 整理新版本方案，再确认后执行。旧版本结果保留在方案历史中；模型变化必须重新估计，图表修改也需明确方案。
5. 审阅结果后，说明需要写哪些部分。对话 Agent 提交标题、章节、篇幅、写作要求与采用的分析步骤；用户可以修改并再次确认。写作 Agent 用选中的实际结果和当前项目 RAG 资料组织正文。分析结束不会自动生成 Word 正文。

## 方法技能

新增八个 Skill，存放在 `assets/skills/empirical-*`，通过产品已有 SkillRuntime 装配；无需用户安装 Codex 插件或上传外部技能包。

| Skill | 范围 |
| --- | --- |
| empirical-analysis-plan | 研究类型识别、步骤制定、方案修改、分析与写作确认 |
| empirical-measurement | 描述统计、相关、适用的组间/独立性检验、信度与 EFA |
| empirical-linear-models | OLS/WLS/GLS、二元/多项/有序模型、计数 GLM、分位数、混合效应 |
| empirical-panel-iv | 固定/随机效应、一阶差分、2SLS、静态 IV-GMM |
| empirical-causal-designs | 同一处理时点的基础 DID、ITS、基础合成控制、PSM/IPW、基础 sharp RDD |
| empirical-prediction | 时间序列、预测模型与验证、基础生存分析 |
| empirical-inference | 适用诊断、有目的的稳健性、分组与交互异质性、系数/森林图 |
| empirical-result-handoff | 真实结果表与代码来源、诊断、图表和写作交接 |

步骤根据研究设计选择，不能固定套用“三次回归”或所有检验。用户说“独立性检验”时应确认具体含义。篇幅和美观要求不能作为增加无目的检验、筛选显著结果或推断因果的理由。

## 执行条件与限制

方法索引在 `assets/skills/empirical-analysis-plan/methods.json`。27 个条目提供指导及依赖；`available` 不代表任意数据都能用。模型失败、不适用或缺少诊断须如实记录，必要步骤未完成不能交给写作 Agent 假装结果完整。

另外 7 类明确标记为需要扩展：错位实施 DID、动态面板 GMM、SEM/CFA、Tobit/Heckman、空间计量、因果机器学习、复杂抽样设计。当前不能暗中用基础方法替代这些方法。Tableau 原生工作簿未接入，不能将普通 PNG 声称为 Tableau 文件。

数据执行在 Windows LPAC + Job Object 中：输入副本只读，禁止网络与子进程，限制内存、时间与输出量。内置 Python 3.14.8；核心依赖为 pandas/numpy/scipy/openpyxl/matplotlib，统计依赖为 statsmodels/scikit-learn/linearmodels/lifelines。分析代码由模型根据确认的步骤与 Skill 生成；自动结果检查验证结构与来源，不能代替人工核验统计设定和解释。

方案按项目与对话保存；确认包含方案 ID、版本、数据 SHA-256；写作确认额外包含写作方案版本。数据变化、旧确认或跨项目确认会被拒绝。结构化结果必须包含实际 N、方法/步骤、汇总表和诊断列表；图表通过受控路径加载到预览。

模型请求会按用户配置发往相应服务商，包含该任务所需的需求、历史摘要、字段和结果上下文；数据计算在本机进行。测试只使用合成数据和模拟模型，不代表已对真实研究的统计结论做人工验证。
